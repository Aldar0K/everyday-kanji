# Кандзи дня

Спокойное мобильное веб-приложение для изучения одного кандзи в день —
для полных новичков, ещё не знающих кану. Интерфейс на русском,
японский показывается с каной и ромадзи. Без очков, стриков и наград.

React + TypeScript + Tailwind CSS v4 + shadcn/ui, собрано на Vite.
Данные и порядок черт — статичный сеанс на 20 кандзи N5, прогресс
хранится в localStorage. Бэкенда пока нет — в планах.

## Разработка

```
npm install
npm run dev     # dev-сервер
npm run build   # сборка
npm run test    # тесты (Vitest)
```
