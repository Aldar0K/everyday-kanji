# Repository conventions

## Commits

Never add a `Co-Authored-By: Claude ...` trailer or a `Claude-Session:` link
to commits in this repository. Commits must be authored solely under the
user's own git identity — no AI co-author attribution, and no appearance in
GitHub's contributor graph.

Follow [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/)
for the subject line (`type(scope): description`, e.g. `fix(strokes): ...`).
Keep the `type`/`scope` keywords in English (they're the spec's structured
tokens), but write the description and body in Russian.
